司雅博的JavaScript —— 程序结构：条件与循环

程序三大结构：顺序、条件（分支）、循环 —— 本页演示条件与循环，所有结果均由页面内的真实代码实时计算

A条件结构（分支）
1if...else if...else
var syb_score = 85; if (syb_score >= 90) { syb_grade = "优秀"; } else if (syb_score >= 80) { syb_grade = "良好"; } else if (syb_score >= 60) { syb_grade = "及格"; } else { syb_grade = "不及格"; }
运行结果：85 分 →
从上往下依次判断，哪个条件先满足就执行哪个分支，都不满足走 else。
2switch...case
var syb_day = new Date().getDay(); switch (syb_day) { case 0: syb_dayName = "星期日"; break; case 1: syb_dayName = "星期一"; break; ... default: syb_dayName = "无效"; }
运行结果：今天是
适合对一个值的多种取值分别处理；break 用于跳出，不写会继续执行下一个 case。
3三元运算符 ? :
var syb_num = 7; var syb_oddEven = syb_num % 2 === 0 ? "偶数" : "奇数";
运行结果：7 →
条件 ? 值1 : 值2 —— 简化版 if...else，适合二选一的赋值。
B循环结构
4for 循环（1~100 求和）
var syb_sum = 0; for (var syb_i = 1; syb_i <= 100; syb_i++) { syb_sum += syb_i; }
运行结果：1+2+...+100 =
初始化、条件、步长写在一行里，适合已知次数的循环。
5while 循环（翻倍到超过 100）
var syb_value = 1, syb_times = 0; while (syb_value <= 100) { syb_value *= 2; syb_times++; }
运行结果：翻倍 次后 syb_value =
先判断条件再执行；适合事先不知道循环次数的场景。
6do...while 循环（至少执行一次）
var syb_j = 10; do { syb_doResult = syb_j; syb_j++; } while (syb_j < 10);
运行结果：条件一开始就不满足，仍执行 1 次，syb_j =
先执行一次再判断条件，循环体至少会运行一次。
7break 与 continue
for (var syb_k = 1; syb_k <= 10; syb_k++) { if (syb_k === 8) { break; } if (syb_k % 3 === 0) { continue; } syb_bcResult += syb_k + " "; }
运行结果：遇到 8 停止、跳过 3 的倍数 →
break 直接跳出整个循环；continue 跳过本次进入下一次。
C嵌套循环（九九乘法表）
for (var syb_row = 1; syb_row <= 9; syb_row++) { for (var syb_col = 1; syb_col <= syb_row; syb_col++) { // 输出 syb_col × syb_row = 乘积 } }
外层循环控制行，内层循环控制列，内层条件是 syb_col <= syb_row，所以呈现三角形。
总结：顺序结构是默认的从上往下执行；条件结构（if...else、switch、三元运算符）让程序学会"选择"； 循环结构（for、while、do...while + break/continue）让程序学会"重复"。 三者组合起来就能表达任何逻辑。
