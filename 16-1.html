B查询与截取（不改变原数组）
1join("-")
var syb_arr = [3, 1, 4, 1, 5, 9, 2, 6]; syb_arr.join("-"); // 用 "-" 把元素串起来
把数组"拼接"成一个字符串，元素之间放分隔符；原数组不变。
2slice(2, 5)
syb_arr.slice(2, 5); // 截取下标 2 ~ 5，不含 5
"切一片"出来，含头不含尾；原数组不变，常用于复制数组 slice(0)。
3concat([7, 8])
syb_arr.concat([7, 8]); // 拼接两个数组
把两个数组"接成一列"，返回新数组，原数组不变。
4indexOf / lastIndexOf
syb_arr.indexOf(1); // 从前往后找 syb_arr.lastIndexOf(1); // 从后往前找
找元素第一次 / 最后一次出现的下标，找不到返回 -1。
5includes(9)
syb_arr.includes(9); // true syb_arr.includes(100); // false
只问"有没有"，返回 true / false，比 indexOf 更直观。
6find / findIndex
syb_arr.find(function (syb_v) { return syb_v > 4; });
按条件找"第一个"满足的元素 / 它的下标，找不到分别是 undefined / -1。
C遍历与高阶函数（逐个处理元素）
7forEach
syb_arr.forEach(function (syb_v, syb_i) { // 依次处理每个元素，无返回值 });
挨个"点名"，只做事不返回新数组；不能用 break 中断。
8map
syb_arr.map(function (syb_v) { return syb_v * 2; });
"一一映射"：每个元素加工后放入新数组，长度不变，原数组不变。
9filter
syb_arr.filter(function (syb_v) { return syb_v > 3; });
"过滤器"：条件为 true 的留下，false 的淘汰，返回新数组。
10reduce
syb_arr.reduce(function (syb_sum, syb_v) { return syb_sum + syb_v; }, 0);
"归并"：从左到右把元素逐个累积成一个值（求和、求最大值等）。
11some / every
syb_arr.some(function (syb_v) { return syb_v > 5; }); syb_arr.every(function (syb_v) { return syb_v > 5; });
some：有一个满足就 true；every：全部满足才 true。
12flat(2)
var syb_nest = [1, [2, 3], [4, [5]]]; syb_nest.flat(2); // 拍平两层
把"盒子套盒子"的多维数组压平成一维，参数表示拍平的层数。
D数组方法速查表（重点：是否改变原数组）
方法作用是否改变原数组返回值
记忆口诀：push / pop 管尾部，unshift / shift 管头部，splice 管任意位置， sort / reverse 管顺序 —— 这 7 个会改变原数组； join / slice / concat / indexOf / includes / find / map / filter / reduce / forEach / some / every / flat 都不改变原数组，它们把结果作为返回值交给你。
