要点：POST / PUT / PATCH 需要在 fetch 的第二个参数里配置 method、headers 和 body； fetch 只有网络层失败（断网、被拒绝）才会 reject，404 / 500 这类 HTTP 错误不会抛异常， 必须用 r.ok 判断后再抛出，这一点和很多库不一样。发送前会先用 JSON.parse 校验请求体，避免把非法 JSON 发给服务器。
