司雅博的JavaScript —— 两种定时器

setTimeout（一次性定时器：到点只响一次）与 setInterval（周期性定时器：每隔一段时间响一次）

AsetTimeout：一次性定时器（到点执行一次）
15 秒倒计时（可提前取消）
var syb_timerId = setTimeout(function () { // 5 秒后只执行这一次 }, 1000); clearTimeout(syb_timerId); // 取消还未执行的定时器
- -
用"递归 setTimeout"实现倒计时：每秒设一个新的一次性定时器，好处是随时可以 clearTimeout 精准取消下一步。
2setTimeout(fn, 0) 也不是"立即执行"
console.log("1. 同步代码"); setTimeout(function () { console.log("3. 定时器回调"); }, 0); console.log("2. 同步代码结束"); // 先输出
// 点击按钮，看真实执行顺序
定时器回调要等"同步代码全部执行完"才会被调用（事件循环机制），哪怕延时写 0 毫秒也一样。
BsetInterval：周期性定时器（每隔一段时间执行一次）
3数字时钟（每 100ms 刷新）
var syb_clockId = setInterval(function () { // 每隔 100ms 执行一次，直到 clearInterval }, 100); clearInterval(syb_clockId); // 停止
--:--:--.---
同一个定时器 id 句柄，启动时保存、停止时 clearInterval，避免重复创建导致"越走越快"。
4下载进度条模拟（到 100% 自动停止）
syb_timer = setInterval(function () { syb_progress += 1; if (syb_progress >= 100) { clearInterval(syb_timer); // 任务完成，必须手动停止 } }, 80);
0%（点击"开始下载"演示周期性执行）
setInterval 会一直执行到 clearInterval 为止；条件满足后记得手动清除，否则定时器会"空转"浪费性能。
C两种定时器对比
对比项setTimeoutsetInterval
执行次数到点后只执行 1 次每隔指定毫秒执行 1 次，循环往复
返回值定时器编号（数字），用于清除定时器编号（数字），用于清除
清除方法clearTimeout(id)clearInterval(id)
典型场景延迟提示、防抖、广告弹窗时钟、轮播图、进度条、轮询刷新
等价写法递归 setTimeout 可模拟 setInterval，且上一次执行完才计时，更不容易"堆积"
三个注意事项：① 定时器的"延时"不精确——回调要排队等同步代码执行完，实际触发时间只会晚不会早； ② 用变量保存定时器 id——需要停止时才能 clearTimeout / clearInterval，同一个按钮反复启动前先清旧的，避免多个定时器叠加； ③ 时间单位是毫秒——setTimeout(fn, 3000) 是 3 秒，不是 3 秒的 3000 分之一。
