1Promise + setTimeout：把"等待"变成可 await 的对象
// 用 setTimeout 模拟耗时工序，返回一个 Promise function syb_wait(syb_ms) { return new Promise(function (syb_resolve) { setTimeout(syb_resolve, syb_ms); // 时间一到，状态从"等待"变"成功" }); }
Promise 是"对未来结果的承诺"：new Promise 时任务开始，调用 resolve 时任务完成。有了它才能用 await 优雅地"等"。
2async/await：异步代码写得像同步一样直白
async function syb_makeDumplings() { await syb_step("buy", 6000); // ① 买原料 await syb_step("take", 2000); // ② 取原料 // ③ 和面、和馅互不依赖 → Promise.all 并行 await Promise.all([ syb_step("dough", 4000), syb_step("fill", 3000) ]); await syb_step("wrap", 5000); // ④ 包饺子 await syb_step("eat", 3000); // ⑤ 吃饺子 }
await 会"等"Promise 完成再往下走；Promise.all 同时启动多个任务、等全部完成，比串行省 3 秒。
总耗时：--（串行需 23 秒，并行节省 3 秒）
// 点击"开始包饺子"，观察 async/await 的执行顺序与 Promise.all 的并行效果
对比记忆：如果全部 await 串行，总耗时 = 6+2+4+3+5+3 = 23 秒； 用 Promise.all 让和面、和馅并行后，总耗时 = 6+2+max(4,3)+5+3 = 20 秒。 await 只能出现在 async 函数里；Promise 一旦完成（resolved）状态就不可再变。
