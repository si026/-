基于知识库的智能客服系统架构
一次提问的完整链路：用户提问 → 预处理与意图识别 → 问答引擎（向量化 → 检索 → 排序 → 多轮管理）→ 从知识库取答案 → 返回用户；未命中的问题经反馈层回流，持续扩充知识库。悬停任意模块查看说明。
科研方向说明：右侧五个虚线框是本系统的科研切入点——①语义匹配与排序算法（句向量模型微调）； ②RAG 检索增强生成（知识库 + 大模型）；③知识库自动构建（从对话日志自动抽取问答对）； ④效果评测体系（命中率 / MRR / 满意度）；⑤反馈闭环学习（点击反馈驱动排序模型在线进化）。 图中绿色 / 橙色 / 紫色小球演示了一次提问经过"用户层 → 引擎 → 知识库 → 引擎"的往返路径。
