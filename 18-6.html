司雅博的JavaScript —— 基于 Mermaid 的智能客服系统图

用"文本即图"的方式绘制：左图是问答引擎的完整流转，下图是知识库存储层的实体关系设计（mermaid.min.js 已本地化）

1智能客服问答流程图 mermaid flowchart TD
一次完整问答的决策链路：提问 → 预处理 → 意图识别分流（咨询类走机器人，交易/投诉类直接转人工）→ 向量化检索 → 按置信度决定"直接回答"还是"推荐相似问题"，最后所有反馈都流入知识扩充闭环。 
flowchart TD
    A["用户提问"] --> B["文本预处理：分词 / 纠错"]
    B --> C{"意图识别"}
    C -- "咨询类" --> D["问句向量化 Sentence-BERT"]
    C -- "交易 / 投诉类" --> H["转人工客服"]
    D --> E["知识库检索：倒排索引 + 向量 ANN"]
    E --> F{"Top-1 置信度是否达到阈值"}
    F -- "达到" --> G["返回标准答案"]
    F -- "未达到" --> I["推荐相似问题列表 或 转人工"]
    G --> J["收集用户反馈：有用 / 没用"]
    I --> J
    J --> K[("未命中问题入库：知识扩充闭环")]
2知识库系统 ER 图 mermaid erDiagram
存储层实体关系设计：用户（USER）发起会话（SESSION），会话包含多条消息（MESSAGE）；知识侧由分类（CATEGORY） 组织问答对（FAQ），每个 FAQ 通过相似问（SIMILAR_QUESTION）扩充问法；每条机器人消息可获得反馈（FEEDBACK）， 会话可转接人工客服（OPERATOR）。 
erDiagram
    USER {
        bigint user_id PK "用户ID"
        varchar nickname "昵称"
        varchar phone "手机号"
        datetime created_at "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "所属用户"
        varchar channel "接入渠道"
        datetime start_time "开始时间"
    }
    MESSAGE {
        bigint message_id PK "消息ID"
        bigint session_id FK "所属会话"
        varchar content "消息内容"
        tinyint sender_type "1用户 2机器人 3人工"
        datetime send_time "发送时间"
    }
    CATEGORY {
        int category_id PK "分类ID"
        varchar category_name "分类名称"
        int parent_id "父分类ID"
    }
    FAQ {
        int faq_id PK "问答对ID"
        int category_id FK "所属分类"
        varchar std_question "标准问"
        text std_answer "标准答"
        int hit_count "累计命中次数"
    }
    SIMILAR_QUESTION {
        int sq_id PK "相似问ID"
        int faq_id FK "所属FAQ"
        varchar question "相似问文本"
    }
    FEEDBACK {
        bigint feedback_id PK "反馈ID"
        bigint message_id FK "被评价消息"
        int faq_id FK "命中的FAQ"
        tinyint is_useful "是否有用"
    }
    OPERATOR {
        int operator_id PK "人工客服ID"
        varchar operator_name "客服姓名"
        varchar group_name "所属班组"
    }

    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    CATEGORY ||--o{ FAQ : "归类"
    CATEGORY ||--o{ CATEGORY : "父子层级"
    FAQ ||--o{ SIMILAR_QUESTION : "扩充问法"
    MESSAGE ||--o| FEEDBACK : "获得评价"
    FAQ ||--o{ FEEDBACK : "被命中评价"
    SESSION }o--o| OPERATOR : "转接人工"
要点：mermaid.min.js 已下载到 cdn 目录本地引用，用"文本即图"的方式维护图表（改文字就改图）； 流程图用 flowchart TD + 菱形判断节点 表达置信度分流；ER 图用 erDiagram + 一对多/可选关系（||--o{ 等乌鸦脚符号） 描述表结构，PK/FK 标注主外键，属性支持中文备注——这也是科研系统设计文档的常用画法。
